# 🎯 Number Guessing Game

A simple number guessing game built with Python. The player tries to guess a randomly generated number, receiving hints to determine whether each guess is too low, too high, or correct.

## 🚀 Features

- Generates a random number for the player to guess.
- Provides hints when a guess is too low or too high.
- Tells the player when the correct number is guessed.
- Beginner-friendly Python project to practise programming fundamentals.

## 🛠️ Technologies Used

- Python 3
- Python standard library (`random` module)

## 📋 Requirements

- Python 3 installed on your computer.

Check your Python version:

```bash
python3 --version
```

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone git@github.com:Rocky2560/Number-Guessing.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Number-Guessing
   ```

3. Run the Python program:

   ```bash
   python3 main.py
   ```

## 🎮 How to Play

1. Run the program.
2. Enter your guessed number.
3. Follow the hints:
   - **Low:** Your guess is smaller than the target number.
   - **High:** Your guess is greater than the target number.
   - **Correct:** You guessed the right number!

Keep guessing until you find the correct number.
